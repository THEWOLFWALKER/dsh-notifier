# 开始使用

[English](guide.en.md)

## 安装

在 DSH 的插件页面安装 **dsh-notifier**，安装后重启 DSH，并刷新页面。侧栏会出现「通知与私聊」。

也可以在终端安装，把 `<profile名>` 换成你正在使用的配置名称：

```bash
dsh plugin add dsh-notifier@latest --profile <profile名>
```

需要帮忙安装时，把[安装说明](AI_INSTALL.md)发给能操作你电脑的助手。

## 收到第一条通知

打开「通知与私聊」，添加一个你平时使用的渠道，按提示填写并保存。点击「测试」，再打开手机查看消息。

只想接收任务进度和结果，配置到这里就够了。

## Telegram 连接不上

打开 Telegram 渠道，在「连接帮助」里可以选择「自定义地址」，也可以点击「自动准备备用连接」。登录 Cloudflare 并选择账号后，点击「一键开启」，插件会准备连接并自动填写保存。机器人凭证沿用已保存的那一份。

详细步骤见[备用连接与自建服务](cloudflare.md)。

## 从手机回复

在支持接收消息的渠道里完成配置。界面提示需要重启时，重启 DSH 一次。

打开这个渠道的「私聊」，按「确认是你 → 选择任务 → 试用」三步完成。确认时，用手机给机器人发一句话，或生成一个确认码并在私聊里发送 `/pair 确认码`。完成后可以回复提问、处理审批，也可以直接继续对话。

请直接私聊机器人。群里不能配对、回复或控制任务。

手机发送 `/help` 可以查看可用命令。需要查看当前任务时，发送 `/tasks`。

## 更换电脑

打开「更多」→「导入旧设置」，导出配置文件，在另一台电脑导入。导入前可以查看变化并选择保留哪些设置。

文件不包含密码和机器人凭证，换电脑后需要重新填写。新导入的渠道会提示「补充配置」，填写并保存后才能使用。

## 日常调整

通知配置保存后通常立即生效。接收消息的配置如果提示「需要重启」，按提示重启一次即可。

升级见[升级说明](upgrade-guide.md)。收不到消息或按钮没有反应，先看[常见问题](TROUBLESHOOTING.md)。
