# Report a problem

Check [troubleshooting](TROUBLESHOOTING.en.md) first. If the problem remains, generate a support report from **More → Help**.

Open a [GitHub issue](https://github.com/THEWOLFWALKER/dsh-notifier/issues) describing what you did, what you expected and what happened. Include the plugin version, support report and steps to reproduce. Hide personal information in screenshots.

Do not share bot tokens, passwords, confirmation codes, complete settings files or private conversations.
