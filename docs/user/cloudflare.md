# Telegram 网关与 Bark 自建

## 一键开启 Telegram 网关

1. 在「通知与控制」里打开 Telegram 配置，点击「一键开启网关」。
2. 点击「登录 Cloudflare」，打开授权页面并完成登录。
3. 选择你的账号。已经配置过的机器人凭证和接收者可以留空；首次使用时填写它们。
4. 保持「部署后自动填写并保存 TG 配置」选中，点击「一键开启」。

完成后，地址会自动填入 Telegram 配置。需要从手机回复时，选中「也用于接收消息」，完成后按提示重启 DSH。

网关沿用同一份机器人凭证，不用额外管理密钥。更换机器人凭证后，再次开启网关，让两边保持一致。

## 使用已有网关

在 Telegram 配置里选择「自定义网关地址」，填写服务的根地址并保存。普通 Telegram 反代和本插件部署的网关都可以使用，无需重新创建机器人。

切回「直连」并保存，就会停止使用网关。

## 自建 Bark

在「通知渠道」里打开「Cloudflare」，登录并选择账号，将服务选为 Bark。

首次添加手机时，选中「允许 Bark App 注册设备」，完成部署。将显示的服务器地址添加到 Bark App，再把 App 提供的 Bark Key 填入插件，点击「绑定渠道」。

添加设备后，取消允许注册并重新部署。个人自建沿用 Bark 官方公开提供的推送配置，不需要另外申请 Apple 证书。

## 中途失败怎么办

看到错误后检查登录和网络，再点击重试。插件会复用已经创建的资源。

部署成功但配置没有保存时，服务地址仍会显示。补齐设置后可以再次绑定；已有配置不会因为失败而被清空。

「解除绑定」只恢复本地连接设置，Cloudflare 上的服务会保留。需要彻底删除时，在自己的 Cloudflare 账号里删除。
