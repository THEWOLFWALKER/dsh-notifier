# 常见问题

## 找不到「通知与控制」

先确认 DSH 插件页面里有 dsh-notifier。安装或升级后重启 DSH，再刷新页面。确认插件装在你正在使用的配置里。

## 保存后收不到消息

点击渠道里的「测试」，查看提示，再打开手机查看消息。确认接收者填写正确，并允许应用通知。

提示凭证无效时，重新填写机器人凭证。Telegram 连接不上时，可以在配置里填写网关地址，或点击「一键开启网关」。

## 能收到通知，不能回复

先检查是否配置了接收消息，再查看有没有「需要重启」提示。完成后在机器人私聊里发送 `/whoami` 查看身份，未配对时重新生成配对码并发送 `/pair 配对码`。

## 配对码不能用

配对码会过期，而且只能使用一次。生成新码，在对应机器人私聊里发送。不要把配对码发到公开群里。

## 提问或审批已经失效

回到电脑查看当前任务。请求可能已经超时，或已经由其他成员处理。

## 网关部署失败

检查 Cloudflare 登录、所选账号和网络，再重试。已创建的服务会保留；不要为了重试反复创建新资源。

更换过 Telegram 机器人凭证时，重新开启网关。

## 导入后渠道不能用

打开提示「补充配置」的渠道，重新填写凭证并保存。导出文件不会包含凭证。

仍解决不了时，按[反馈说明](SUPPORT.md)提供问题现象和诊断摘要。
