# 常见问题

## 找不到「通知与私聊」

先确认 DSH 插件页面里有 dsh-notifier。安装或升级后重启 DSH，再刷新页面。确认插件装在你正在使用的配置里。

## 保存后收不到消息

点击渠道里的「测试」，查看提示，再打开手机查看消息。确认接收者填写正确，并允许应用通知。

提示凭证无效时，重新填写机器人凭证。Telegram 连接不上时，打开渠道的「连接帮助」，点击「自动准备备用连接」。

## 能收到通知，不能回复

先检查是否配置了接收消息，再查看有没有「需要重启」提示。完成后打开渠道的「私聊」，按提示确认是你；还没确认时，生成一个确认码并在机器人私聊里发送 `/pair 确认码`。

## 确认码不能用

确认码会过期，而且只能使用一次。重新生成，在对应机器人私聊里发送。不要把确认码发到公开群里。

## 提问或审批已经失效

回到电脑查看当前任务。请求可能已经超时，或已经由其他成员处理。

## 备用连接设置失败

检查 Cloudflare 登录、所选账号和网络，再重试。已创建的服务会保留；不要为了重试反复创建新资源。

更换过 Telegram 机器人凭证时，重新开启备用连接。

## 导入后渠道不能用

打开提示「补充配置」的渠道，重新填写凭证并保存。导出文件不会包含凭证。

仍解决不了时，按[反馈说明](SUPPORT.md)提供问题现象和支持报告。
