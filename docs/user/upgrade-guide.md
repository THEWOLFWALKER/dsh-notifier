# 升级

在 DSH 插件页面更新 dsh-notifier，然后重启 DSH、刷新页面。

也可以重新运行安装命令：

```bash
dsh plugin add dsh-notifier@latest --profile <profile名>
```

升级前可以在「通知渠道」→「导入 / 导出」保存一份配置文件。文件不包含密码和机器人凭证，不要把它当作完整备份。

升级后打开「通知与控制」，查看原来的渠道是否还在，发送一条测试消息。接收消息的渠道如果提示重启，再按提示处理。

界面仍是旧版时，确认更新的是正在使用的 DSH 配置，重启后刷新页面。仍有问题，按[常见问题](TROUBLESHOOTING.md)排查。
