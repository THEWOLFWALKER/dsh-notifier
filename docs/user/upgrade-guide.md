# 升级

在 DSH 插件页面更新 dsh-notifier，然后重启 DSH、刷新页面。

也可以重新运行安装命令：

```bash
dsh plugin add dsh-notifier@latest --profile <profile名>
```

升级前可以打开「更多」→「导入旧设置」保存一份配置文件。文件不包含密码和机器人凭证，不要把它当作完整备份。

升级后打开「通知与私聊」，查看通知渠道并发送一条测试消息。私聊需要单独开启：检查接收消息渠道卡片里的私聊开关；开启后按界面提示重启 DSH。关闭私聊会立即拒绝新的远程操作，并保留已保存的账号信息。

界面仍是旧版时，确认更新的是正在使用的 DSH 配置，重启后刷新页面。仍有问题，按[常见问题](TROUBLESHOOTING.md)排查。
